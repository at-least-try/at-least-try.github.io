## Current implementation

This repo includes a static portfolio landing experience with:

- `index.html`
- `style.css`
- `script.js`

It is intentionally built to run without a local web server.

## Run locally (no server required)

1. Clone/download the repository.
2. Open `index.html` directly in your browser.

```bash
git clone https://github.com/at-least-try/at-least-try.github.io.git
cd at-least-try.github.io
# then open index.html by double-clicking it
```

## Hosting

- Works as a static site on GitHub Pages.
- Git is for version control and deployment flow (`commit/push`), while the browser renders the static files directly.
